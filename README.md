## 🚀 How to Run

1. Clone this repository.
2. Open **Android Studio**.
3. Select **Open** and choose the required practical folder.
4. Wait for Gradle synchronization to complete.
5. Connect an Android device or start an emulator.
6. Click **Run ▶**.
